RTF = generation time ÷ audio length. Under 1.0 means faster than playback. That number, measured on the device you are holding, is what decides whether a model is usable in an app.

  • Everything runs client-side via ONNX Runtime Web / WebAssembly. GitHub Pages can't send the COOP/COEP headers that unlock multi-threaded WASM, so this is single-threaded — a native Android build with threads will be meaningfully faster.
  • Models download once, then the browser caches them.
  • Piper voices: CC0 / public-domain training data, MIT-licensed models. Supertonic 3: OpenRAIL-M. MMS-TTS: CC-BY-NC.
